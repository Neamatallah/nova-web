## 📖 About the Project

**Nova** is a creative studio website created as part of my **Full-Stack Development journey**.

The website focuses on creative services including:

* Brand Design
* Web Design
* Creative Direction
* Development

The main goal of this project was to practice building a complete responsive website using **HTML and CSS**, while applying modern CSS layout techniques and creating a clean, elegant visual design.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Neamatallah/nova-web.git
```

### 2. Navigate to the Project

```bash
cd nova-web
```

### 3. Open the Project

Open the project folder in **Visual Studio Code** and open `index.html` in your browser.

You can also use a local development tool such as **Live Server** if needed.
